# student-learning-management
The Student Learning Management System (LMS) is a responsive, web-based application designed to make online learning simple, organized, and interactive. It provides a user-friendly interface where students can explore courses, access learning materials, track their progress, and manage their learning activities.

This project is developed using HTML, CSS, and JavaScript as a frontend-only application.

✨ Features
Modern and responsive user interface
Course listing and course details
Student dashboard
Learning progress tracking (demo)
Search and filter courses
Mobile-friendly design
Interactive elements using JavaScript
Attractive layout, colors, and visual elements
